# `forcefill.clean_structure`

Removing crystallographic water, bulk counter-ions and crystallization additives
from a structure, in memory or on disk. See {doc}`../guide/cleaning` for what the
defaults keep and why.

The residue-name tables this module works from — `WATER_RESIDUES`,
`BULK_ION_RESIDUES`, `STRUCTURAL_METAL_RESIDUES` and `ADDITIVE_RESIDUES` — are
documented on {doc}`constants`.
